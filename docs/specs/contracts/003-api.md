# API contract: dashboard (specs 001-003, consumed by 005-009)

Server: Node + Express, bound to `127.0.0.1`, port from `PORT` (default `4000`). All endpoints are `GET`, JSON, read-only. No auth. Any unexpected exception returns HTTP 500 `{ "error": "<short message>" }`.

Environment:

| Variable | Meaning | Default |
|---|---|---|
| `PORT` | server port | `4000` |
| `CLAUDE_PROJECTS_DIR` | transcript root scanned by spec 001 | `~/.claude/projects` |
| `GOOGLE_APPLICATION_CREDENTIALS` | path to the service account key file (spec 002) | none (Sheets then report `error`) |

Static files: if `web/dist` exists, the server serves it at `/` (relative to the repo root). The frontend dev server proxies `/api` to `http://127.0.0.1:4000`.

## Shared shapes

```ts
type Status = 'Extracted' | 'Confirmed' | 'Spec Written' | 'Rejected'

type Row = {            // one Sheet row; every field is a string, missing = ""
  id: string; title: string; summary: string; source: string
  priority: string; status: string; spec: string
}

type SessionItem = { sessionId: string; title: string; lastActivity: string }  // ISO 8601, title "" if none

type Requirements = {
  status: 'ok' | 'no-sheet' | 'error'
  counts: { Extracted: number; Confirmed: number; 'Spec Written': number; Rejected: number }  // all 0 unless status is 'ok'
  rows: Row[]           // [] unless status is 'ok'
  error?: string        // short text, only when status is 'error'; never contains key material
}
```

## GET /api/projects

Response 200:

```json
{
  "activeMinutes": 5,
  "kpis": { "activeProjects": 3, "sessionsToday": 14, "openRequirements": 9 },
  "projects": [
    {
      "name": "nin-claude-dashboard",
      "path": "f:/naim/nin-claude-dashboard",
      "sessions": 8,
      "lastActivity": "2026-10-05T10:20:00.000Z",
      "active": true,
      "sessionList": [ { "sessionId": "…", "title": "…", "lastActivity": "…" } ],
      "requirements": { "status": "ok", "counts": { "Extracted": 0, "Confirmed": 3, "Spec Written": 5, "Rejected": 0 }, "rows": [] }
    }
  ]
}
```

- `name` is the last segment of `path`. `sessions` equals `sessionList.length`.
- Sorted: `active` first, then `lastActivity` descending.
- `kpis.openRequirements` = sum of `Extracted` + `Confirmed` across projects. `kpis.sessionsToday` = sessions whose `lastActivity` is on the same local day as now.

## GET /api/feed

Query: `project` (optional, matches `name` exactly). Response 200: `FeedItem[]`

```json
[ { "project": "nin-claude-dashboard", "sessionId": "…", "title": "…", "lastActivity": "…" } ]
```

Newest first by `lastActivity`, at most 100. An unknown `project` returns `[]` (not an error).

## GET /api/pipeline

Query: `project` (optional). Response 200:

```json
{ "Extracted": [], "Confirmed": [], "Spec Written": [], "Rejected": [] }
```

Each array holds `Row & { "project": string }`, in project order then Sheet order. A row whose `status` is not one of the four is left out. An unknown `project` returns four empty arrays.

## Notes

- Sheet failures never change the HTTP status: they appear as `requirements.status = 'error' | 'no-sheet'` on that project only.
- The server never writes to `~/.claude` or to any Sheet.
